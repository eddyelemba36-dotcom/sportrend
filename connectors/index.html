📖 Documentation API

Authentification

Clé API envoyée via header X-API-Key ou paramètre ?key=

Endpoints

GET /api/v1/healthStatut du service et nombre de matchs
curl -H "X-API-Key: demo_key_001" http://185.182.9.199:3000/api/v1/health
GET /api/v1/matchesTous les matchs avec cotes
curl -H "X-API-Key: demo_key_001" http://185.182.9.199:3000/api/v1/matches?source=espn&sport=NFL&status=live
GET /api/v1/matches/:id/markets30+ marchés de paris pour un match
curl -H "X-API-Key: demo_key_001" http://185.182.9.199:3000/api/v1/matches/esnp_soccer_eng_1_401879301/markets
GET /api/v1/competitionsCompétitions disponibles
GET /api/v1/live/nowMatchs en direct uniquement
GET /api/v1/resultsRésultats récents
GET /api/v1/infoStatistiques détaillées

Paramètres de filtrage

?source=espnFiltrer par source (espn, unibet, betexplorer, flashscore)
?sport=NFLFiltrer par sport (Football, NFL, MLB, NBA, NHL, etc.)
?status=liveStatut (live, upcoming, finished)
?limit=50Limiter le nombre de résultats

WebSocket (temps réel)

ws://185.182.9.199:3000/ws?key=demo_key_001

Reçoit les mises à jour des matchs et cotes en temps réel
